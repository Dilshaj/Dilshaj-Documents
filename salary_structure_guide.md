# Salary Breakdown & Calculation Guide

This guide explains how each figure in the Annexure A salary table is calculated, defining all key payroll terms in simple language with an exact numerical example.

---

## 1. Key Payroll Terms Explained

### **CTC (Cost to Company)**
* **What it means**: The total annual expense the company incurs to employ you.
* **Formula**: $\text{CTC} = \text{Gross Salary (A)} + \text{Statutory Benefits (B)}$

---

### **Section A: Gross Salary**
*Gross Salary is the total direct salary earned by the employee before any deductions.*

1. **Basic Salary**
   * **What it is**: The core foundational component of your salary.
   * **Formula**: **50% of Gross Salary** ($\text{Gross} \times 0.50$)
   * **Why it matters**: EPF (Provident Fund) contributions are calculated strictly as 12% of this Basic Salary.

2. **House Rent Allowance (HRA)**
   * **What it is**: An allowance provided to assist with housing expenses.
   * **Formula**: **40% of Basic Salary** ($\text{Basic} \times 0.40$)
   * **Tax Benefit**: Eligible for tax exemption under IT rules against valid rent receipts.

3. **Special Allowance**
   * **What it is**: A flexible balancing allowance that ensures the total salary components equal the exact offered CTC.
   * **Formula**: $\text{Annual CTC} - \text{Basic} - \text{HRA} - \text{Statutory Benefits (B)}$

---

### **Section B: Statutory Benefits (Employer Contributions)**
*These are statutory contributions paid by the employer on top of your Gross Salary into government welfare funds for your benefit.*

1. **Employer PF Contribution**
   * **What it is**: The employer's statutory deposit into your EPFO (Employee Provident Fund) account.
   * **Rate**: **12% of Basic Salary** ($\text{Basic} \times 0.12$)

2. **Employer ESI Contribution**
   * **What it is**: Employer's contribution to ESIC for medical and health insurance coverage.
   * **Rate**: **3.25% of Gross Salary** ($\text{Gross} \times 0.0325$)
   * **Applicability**: Required by law only if Monthly Gross Salary is $\le$ ₹21,000.

---

### **Section C: Deductions (Employee Share)**
*These amounts are deducted from your Gross Salary and deposited into your respective PF and ESI government accounts.*

1. **Employee PF Contribution**
   * **What it is**: Your own contribution towards your retirement savings in EPFO.
   * **Rate**: **12% of Basic Salary** ($\text{Basic} \times 0.12$)

2. **Employee ESI Contribution**
   * **What it is**: Your contribution for ESIC medical benefit access.
   * **Rate**: **0.75% of Gross Salary** ($\text{Gross} \times 0.0075$)
   * **Applicability**: Only applicable if Monthly Gross Salary is $\le$ ₹21,000.

---

### **Estimated Net Pay (Take-Home Salary)**
* **What it is**: The actual cash amount transferred to your bank account each month/year.
* **Formula**: $\text{Estimated Net Pay} = \text{Gross Salary (A)} - \text{Deductions (C)}$

---

## 2. Step-by-Step Walkthrough Example (₹2,00,000 Annual CTC)

Below is an exact calculation walkthrough for an annual CTC of **₹2,00,000** (₹16,667/month):

| Component | Annual Calculation Formula | Annual Figure (₹) | Monthly Calculation | Monthly Figure (₹) |
| :--- | :--- | :---: | :--- | :---: |
| **A. GROSS SALARY** | | | | |
| Basic Salary | 50% of Gross | **₹91,533** | Annual / 12 | **₹7,628** |
| House Rent Allowance (HRA) | 40% of Basic | **₹36,613** | Annual / 12 | **₹3,051** |
| Special Allowance | CTC − Basic − HRA − Benefits | **₹54,920** | Annual / 12 | **₹4,577** |
| **Total Gross Salary (A)** | Basic + HRA + Special Allowance | **₹1,83,066** | Basic + HRA + Special | **₹15,256** |
| | | | | |
| **B. STATUTORY BENEFITS** | | | | |
| Employer PF Contribution | 12% of Basic | **₹10,984** | Annual / 12 | **₹915** |
| Employer ESI Contribution | 3.25% of Gross | **₹5,950** | Annual / 12 | **₹496** |
| **Total Contribution (B)** | Employer PF + Employer ESI | **₹16,934** | Employer PF + ESI | **₹1,411** |
| | | | | |
| **TOTAL COST TO COMPANY** | **Gross (A) + Benefits (B)** | **₹2,00,000** | **Gross (A) + Benefits (B)** | **₹16,667** |
| | | | | |
| **C. DEDUCTIONS** | | | | |
| Employee PF Contribution | 12% of Basic | **₹10,984** | Annual / 12 | **₹915** |
| Employee ESI Contribution | 0.75% of Gross | **₹1,373** | Annual / 12 | **₹114** |
| **Total Deductions (C)** | Employee PF + Employee ESI | **₹12,357** | Employee PF + ESI | **₹1,029** |
| | | | | |
| **ESTIMATED NET PAY** | **Gross (A) − Deductions (C)** | **₹1,70,709** | **Gross (A) − Deductions (C)** | **₹14,227** |

---

## 3. Summary Cheat-Sheet

* $\text{Total CTC} = \text{Gross Salary} + \text{Employer Benefits}$
* $\text{Net Salary (Take-Home)} = \text{Gross Salary} - \text{Employee Deductions}$
* **PF Contribution**: 12% of Basic (both Employer & Employee contribute 12% each).
* **ESI Contribution**: 3.25% Employer + 0.75% Employee (only for monthly gross $\le$ ₹21,000).
